# Секретное приглашение 💌

Сайт-приглашение на свидание: конверт с кодом → полароиды → детали свидания → кнопка «Я принимаю приглашение!».
Один файл `index.html` + папка `photos/`. Никаких сборок и зависимостей.

## Что поменять перед деплоем

Открой `index.html`, найди блок `НАСТРОЙКИ` в самом начале `<script>` (внизу файла):

```js
const CORRECT_PASSWORD = 12; // Укажи здесь итоговое число
const DATE_ISO = '2026-10-24T15:00:00+03:00'; // для обратного отсчёта
const EXTRA_HINT = '...'; // доп. подсказка после 3 неверных попыток
const REPLY_TEXT = '...'; // текст, который она отправит тебе кнопкой «Написать мне „Да“»
```

- **Подписи к фото** — прямо в HTML, в тегах `<figcaption>`.
- **Заменить фото** — положи файл в `photos/` и поменяй `src` у нужного `<img>`.

## Деплой на GitHub Pages (без командной строки)

1. Зайди на github.com → **New repository**. Имя, например, `for-you`. Тип — **Public**. Создать.
2. На странице репозитория: **Add file → Upload files**. Перетащи туда `index.html`, `README.md` и **папку** `photos` целиком. Нажми **Commit changes**.
3. **Settings → Pages**. В «Build and deployment»: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)**. **Save**.
4. Подожди 1–2 минуты и обнови страницу настроек — сверху появится ссылка вида
   `https://<твой-логин>.github.io/for-you/`

Любые правки потом — просто редактируешь файл на GitHub (значок карандаша) и коммитишь, сайт обновится сам через минуту.

### Через git (если удобнее)

```bash
cd date-invite
git init && git add . && git commit -m "Секретное приглашение"
git branch -M main
git remote add origin https://github.com/<твой-логин>/for-you.git
git push -u origin main
```
Дальше шаг 3 выше.

## Полезное

- После того как нажмёшь «Я принимаю приглашение!» сам (при тестировании), кнопка запомнит это в браузере. Открой ссылку с `?reset` в конце — состояние сбросится: `https://<логин>.github.io/for-you/?reset`
- Код — для игры, а не для защиты: его можно увидеть в исходнике страницы. Репозиторий публичный, фото в нём видны всем, кто его найдёт. Поисковики сайт индексировать не будут (`noindex`).
- При отправке ссылки в Telegram/Instagram в превью будет «Для тебя кое-что секретное 🔒» — без фото, сюрприз не испортится.
